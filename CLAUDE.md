# Career Agent

@AGENTS.md

Use `/job-application-agent` for application work. Its Claude entrypoint loads the same canonical workflow as Codex. The CLI is agent-independent. Use `npm run setup` for a new private workspace and `npm run doctor` for local diagnostics.

Browser and email tools must be configured in the user's own Claude Code session. If unavailable, prepare saved materials and give a manual browser handoff. Never claim a live form was filled from a CLI packet alone. Scheduling instructions are specific to the user's selected host; no Codex automation tool is assumed in Claude Code.
