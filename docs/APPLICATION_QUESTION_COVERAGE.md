# Application question coverage

The **Start here** questionnaire is based on fields observed on public employer application forms, checked October 7, 2026. It captures candidate answers once in configured private storage and a local candidate skill. It is a preparation aid: the agent still inspects every live form and its controls before filling or submitting.

Finance forms can ask for a full employment timeline and conditional disclosures that a short intake cannot safely pre-answer. The agent should inspect the actual controls, use the résumé and confirmed profile as evidence, and put missing dates or personal/legal answers in **Review queue → Needs answers**. A license or professional claim must not be inferred from a résumé keyword or a related project.

Some employers also publish rules for AI-assisted responses or assessments. For example, BCG US allows AI as an application preparation aid while emphasizing the candidate's own voice; BCG Switzerland says its cognitive test must be completed without tools. Check the live employer's instructions before drafting or filling those steps.

**Reuse rules:** Blank optional answers stay blank. A saved self-identification answer can automatically fill only a single-choice control with the same question and exact available option. Different wording, multi-select controls, missing options and consent requests go to **Review queue → Needs answers**. The agent may read context-only answers from the private candidate skill to understand a candidate's own wording, but must not invent a form option or infer an identity. Protected veteran status and general veteran or active service are separate questions. Source pages can change; live form inspection takes precedence over this inventory.

The dashboard does not ask for date of birth, Social Security number or medical details. These are not needed for reusable job search and application preparation. The local candidate skill remains in ignored `.data/` files; the database uses the configured SQLite or Supabase backend. A full helper export includes saved answers, so review it before sharing. Do not include filled candidate responses in issues, logs or commits.
