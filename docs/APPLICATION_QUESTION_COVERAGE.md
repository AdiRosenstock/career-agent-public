# Application question coverage

The **Start here** questionnaire is based on fields observed on public employer application forms, checked October 7, 2026. It captures candidate answers once in configured private storage and a local candidate skill. It is a preparation aid: the agent still inspects every live form and its controls before filling or submitting.

| Public application | Questions observed | Dashboard coverage |
| --- | --- | --- |
| [Proto](https://job-boards.greenhouse.io/proto/jobs/6148882004) | School, degree, discipline, portfolio, work authorization, sponsorship, source of referral, salary requirements, office location, gender, Hispanic/Latino and veteran status | Education, portfolio, authorization, pay and optional self-identification. Referral and location-specific commitments stay per application. |
| [Harris Associates](https://boards.greenhouse.io/embed/job_app?token=4584130006) | Referral, compensation, authorization, sponsorship, gender, protected veteran status, sexual orientation, race/ethnicity and disability status | Exact single-choice options for the observed gender, protected veteran, sexual orientation and disability questions. |
| [MongoDB](https://boards.greenhouse.io/embed/job_app?token=6493059) and [Benchling](https://boards.greenhouse.io/embed/job_app?token=7278188) | Single-choice race, Hispanic/Latino, gender identity and other voluntary demographic fields; MongoDB separately requests demographic data processing consent | Exact choices for the observed single-choice labels. A candidate's own race/ethnicity wording is saved for context because other forms have different categories or allow several selections. Consent stays per application. |
| [Five Rings](https://boards.greenhouse.io/embed/job_app?token=4808867008) | Gender identity, race/ethnicity, sexual orientation, transgender identity, disability/chronic condition, veteran or active service, plus separate data-retention and demographic consent boxes | Optional identity and military-service context. | [Morgan & Morgan](https://job-boards.greenhouse.io/morganmorganjobsapplynow/jobs/6147389004) | Work authorization, sponsorship, education threshold, family at employer, background-check willingness, salary expectations, start timing, schedule, prior employment and SMS consent | General candidate facts and pay/start context are collected. Employer-specific eligibility, family relationships, prior employment, schedule and SMS consent stay per application. |

**Reuse rules:** Blank optional answers stay blank. A saved self-identification answer can automatically fill only a single-choice control with the same question and exact available option. Different wording, multi-select controls, missing options and consent requests go to **Review queue → Needs answers**. The agent may read context-only answers from the private candidate skill to understand a candidate's own wording, but must not invent a form option or infer an identity. Protected veteran status and general veteran or active service are separate questions. Source pages can change; live form inspection takes precedence over this inventory.

The dashboard does not ask for date of birth, Social Security number or medical details. These are not needed for reusable job search and application preparation. The local candidate skill remains in ignored `.data/` files; the database uses the configured SQLite or Supabase backend. A full helper export includes saved answers, so review it before sharing. Do not include filled candidate responses in issues, logs or commits.
